# Kontekst
Ja sam početnik i ovo je moja prva web aplikacija. Zadatak je u fajlu ZADATAK.md.
Radim na Windows-u u PhpStorm-u. PHP 8.3 i Composer su instalirani preko winget-a, MySQL je lokalni.
